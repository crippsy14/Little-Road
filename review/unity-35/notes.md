## Scope and provenance

`baseline-manifest.json` freezes the authoritative candidate-29 export hash and shared-source hashes before integration. Current old traffic source is candidate 30 and remains parked; this milestone does not pretend to have recovered exact candidate-29 source. The same new executable runs reference versus context for the solo/rear controls. Historical 29 remains a separate export, not silently relabelled as the current traffic policy.

`ContextDriverPolicy` is separately selectable and never calls `TrafficDriverPolicy`. It uses sampled track-width preference and danger, interpolates a continuous target, constrains adjacent occupied space, follows a smooth approach through normal inputs, and applies moving-leader and immediate braking constraints. Clear road delegates to the existing clean reference follower. Shared vehicle forces/equipment, ordered gates and collision response remain authoritative. This is an original experimental adaptation of the published design, not F1 source code or a completed physical-feasibility planner.

Only declared Cedar solo, pace-solo, rear-control, follow and pass fixtures are currently enabled for this prototype. Narrow walls, emergency probe, recovery, corner and field fixtures require further integration/validation. This restriction makes the unvalidated scope explicit; it is not a replacement for the required 24-car outcome.
