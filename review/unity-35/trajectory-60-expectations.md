# Checked in-progress pass continuation

Hypothesis from59: resetting an unchanged pass to the start of a22–60m transition every planning update delays useful lateral motion, prolonging moving-leader speed limits.60 tests retaining the actual path geometry and consumed progress only while the preferred destination is unchanged within.001m, traffic remains relevant, the path is an unfinished non-guide/non-rejoin/non-coast pass, and more than.6m of lateral movement remains. This tolerance represents numeric equality, not a new lane-change quantisation threshold.

Every retained candidate is forecast again from the current measured state and must pass the unchanged whole-body road envelope, moving side-entry, current adjacent/rear corridor and scenery checks. If rejected, try a newly anchored path to the same target before moving to other candidates. Live leader and immediate safety rules stay unchanged. A changed destination or cleared traffic immediately returns to normal replanning. There is no equipment, collider, track-limit, risk-margin or control-cadence change.

The feature is opt-in via `--retain-pass-trajectory`, requiring physical road feasibility. Disabled must preserve59 field behaviour. Prospective worker preparation and actual selection must build the same candidate despite progress being advanced at different call boundaries; consumed distance participates in exact reuse identity and is preserved when committing. Report attempted/accepted/rejected continuations. Optional continuation audit records actual accepted candidates; null audit must remain harmless.
