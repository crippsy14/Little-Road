# Third-party visual assets

## Kloofendal 48d Partly Cloudy (Pure Sky)

- Provider: [Poly Haven](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky).
- Authors: Greg Zaal (original photography), Jarod Guest (sky edits).
- Licence: [CC0](https://polyhaven.com/license), [CC0 1.0 deed](https://creativecommons.org/publicdomain/zero/1.0/).
- Download: `https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/2k/kloofendal_48d_partly_cloudy_puresky_2k.hdr`.
- Retrieved: 17 September 2026. Size: 5,451,493 bytes. Provider MD5: `2eba3a4d7eeb23cbfbeca364c97e7980`; verified after download.
- Local file: `unity/Assets/Resources/Sky/kloofendal_48d_partly_cloudy_puresky_2k.hdr`.
- Use: cloud sky and environment reflections. The original HDR file is unchanged; runtime sampling rotates the sky and adjusts exposure, with the directional light aligned to its brightest pixel. This is third-party photography, not original project artwork.

## Terrain materials

- [Rock 08](https://polyhaven.com/a/rock_08), by Rob Tuytel, Poly Haven, CC0. Original scan width 1.5m; the world-space shader can rescale its detail for the authored formations.
- [Grass Ground](https://polyhaven.com/a/grass_ground), by Charlotte Baglioni, Poly Haven, CC0. Original scan width approximately 2.51m. The provider API records dimensions in millimetres ([API schema](https://github.com/Poly-Haven/Public-API/blob/master/swagger.yml)).
- Each uses the 2K diffuse JPG, OpenGL normal PNG and AO/roughness/metal JPG from the provider. Downloaded 17 September 2026; every file was checked against its provider MD5. Exact source URLs, sizes, MD5 and SHA256 are recorded in `review/unity-09/material-downloads.json` alongside the source API metadata.
- Local files: `unity/Assets/Resources/Surfaces/rock_08` and `unity/Assets/Resources/Surfaces/grass_ground`. Source images are unchanged. Unity imports normals as normal maps and scalar maps as linear data; the runtime terrain shader changes mapping, tint and surface blending. These are third-party photographic surface maps.
- The authored roadside/bridge masonry study also uses Rock 08 diffuse and normal maps with a separate UV scale, restrained normal strength and varied limestone tints. Its chamfered stone geometry is generated by the project; the surface photography retains the credit above.
- The coastal relief revision uses the same credited Rock 08 surface on original fractured outcrops and fallen blocks. Their meshes are generated by the project from authored profiles and intersecting cutting planes.

The car, village, base landscape and vegetation meshes remain project-generated. Engine/software licences are tracked separately in the Windows distribution.
