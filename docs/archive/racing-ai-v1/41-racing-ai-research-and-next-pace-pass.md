These sources support techniques and experiment design, not promised speed gains. Real-vehicle methods have different budgets and objectives from an approachable car-adventure. Existing equipment physics, personalities, controls, drafting, recovery and accepted race feel remain the foundation.

## First pace experiment after performance

Start with a measured lost-time audit, then choose one intervention. Current code already has common downstream gates, local curvature speed envelopes, two physical shortlisted paths, owned worker prediction and guarded result reuse. Reimplementing those ideas would add complexity without establishing an improvement.

1. Freeze the retained performance export/settings, both courses, exact roster/loadouts and seed set. Preserve the current scheduler as a declared variable; never attribute a scheduling change to faster driving logic.
2. Measure collective car-seconds, car0 finish/rank/first-corner position, field spread, per-sector loss, throttle/coast/brake time, contacts/severity, recoveries, missed gates and frame tails. Retain all results, including failures. Different equipment needs matched solo baselines before claiming lost traffic time.
3. Attribute pedal losses to the actual follower, moving-leader constraint, immediate guard and unresolved-path fallback. Pair each slowdown with closing speed, lateral overlap, curve/steering limit and available progress. Count a needless brake only when the counterfactual is tested, not merely because another car is nearby.
4. Replay selected low-progress snapshots offline: compare the chosen path with the remaining generated candidates using the same physical model and common downstream gate. Include time and exit speed. This costs no extra per-frame work in ordinary play and can identify whether ranking, candidate coverage or tracking causes the largest losses.
5. Implement only the largest evidenced cause. Candidates include better candidate-time estimates, an outside-corner continuation, or removing a duplicated speed reserve after shared-physics calibration. Do not broadly reduce margins or disable the immediate guard to chase an80-second number.

## Keep/reject contract

Use at least three paired seeds on each course after the targeted solo/passing fixture succeeds. Aim for a repeatable decrease in collective time and improved fast-car opportunity conversion, with the same equipment. Report median and individual outcomes; car0 should not get faster by making the rest of the field slower. Preserve24 finishers, checkpoint order, bounded incidents and zero new assisted-recovery patterns. Occasional contact remains part of the game's intended racing; sustained pushing, overlapping bodies or recurring pileups do not count as progress.

Measure rendering with the retained performance setup. A faster simulated race that restores visible hitches is not a successful combined change. The historical80-second Cedar aspiration is a direction for a particular fixture, not a universal target across changed rosters/tracks. Final judgement also needs the user's moving review; telemetry alone cannot certify natural racing.
