# Game implementation

Godot 4.7.2 project. Open `project.godot` and run the main scene.

The procedural coastal world, original imported car and initial adventure systems are implemented. `tests/run_tests.gd` exercises important progression and driving behaviours; run with the console executable, `--headless --fixed-fps 60 --script res://tests/run_tests.gd` and the project path. Visual capture uses a rendered run and the user argument `--capture-dir=ABSOLUTE_FOLDER`.

Headless tests do not prove visual fidelity or human handling quality. Consult `../review/` for current evidence and remaining gaps.
